# MegaChunkGdn 末状态精度复现与定位

**首要误差来源是 `chunk_h` 把衰减后的键 `K̃` 舍入成 BF16，再用它更新状态。** 同一组输入在 910B3 上的末状态相对 CPU FP64 误差为 5.6315%。用硬件实际的中间量重放这一阶段并保留原有舍入，得到 5.6316%。只让 `K̃` 保留 FP32，误差降到 3.7260%，通过原测试容差。这个变化是在 CPU 重放中验证的，下面的 NPU 实测均使用原修复版算子。[衰减后 K 的类型转换](https://github.com/singzhou/xllm-ops/blob/614c9a13ab6749cd07a7e840c2a24d6626112add/xllm_ops/mega_chunk_gdn/op_kernel/chunk_h.cpp#L1795-L1798) · [Cube 状态更新乘法](https://github.com/singzhou/xllm-ops/blob/614c9a13ab6749cd07a7e840c2a24d6626112add/xllm_ops/mega_chunk_gdn/op_kernel/chunk_h.cpp#L1360-L1372)

## NPU 复现

使用 Ascend 910B3 物理 7 号卡、CANN 9.2.0，以及从 `614c9a13ab6749cd07a7e840c2a24d6626112add` 重编的算子。直接调用 Mega 和 vLLM Ascend 使用的原生 FLA-NPU 算子。合成输入使用 seed 71、2048 token、4 个 key head、12 个 value head、head dim 128、零初始状态和 BF16 Q/K/V。每个 key head 内各 token 的 K 完全相同。每 token 的 log gate 在 −0.002 到 −0.001，beta 生成时在 0.975 到 0.985，随后转为 BF16。最大绝对误差 ≤ 0.01 或相对 RMSE < 5% 即通过。

| 2048 token 末状态 | 相对 RMSE | 最大绝对误差 | 判定 |
| --- | ---: | ---: | --- |
| Mega 对 CPU FP64 | 5.6315% | 0.012978 | 超差 |
| Mega 对原生 FLA-NPU | 6.0843% | 0.015352 | 超差 |
| 原生 FLA-NPU 对 CPU FP64 | 2.8042% | 0.007444 | 通过 |

两次 Mega 调用的输出、逆矩阵、W/U、各块状态、`V_new` 和末状态逐位一致。逆矩阵与同一份 NPU KKT 的 FP64 解相差最多 0.000592，输出仍过精度验收。沿 128-token 块边界比较状态，第 3 块末尾第一次超差。截取原输入独立运行的 128、256、384、512、1024、1536 和 1920 token 末状态，均与完整输入在相同边界的内部状态逐位一致。[原始数据](state-diagnosis.json) · 运行日志 · [原始逆矩阵和输出对比](published-validation.json)

## 误差如何进入状态

该样本中，`K̃_i = exp(g_last - g_i) × K_i` 本应让同一个 K 方向只改变长度。乘完后将 K 的每个分量分别舍入成 BF16，会让部分向量偏离这个方向。随后的 `K̃ᵀ @ V_new` 把这些偏差写入状态。实测垂直于原 K 方向的误差范数占总误差范数的 75.3%。只去掉这一次舍入，垂直误差从参考状态范数的 4.24% 降到 0.40%，沿 K 的误差约为 3.70%。

精度消融读取 NPU 实际输出的 gate、W/U，按内核的 BF16 转换位置重放 `chunk_h`。从硬件每块的起始状态重建 `V_new`，2048 token 的最后一块与设备逐位相同。整个递推直接使用设备实际的 `V_new` 也得到 5.6315% 的末状态误差。

| CPU 重放设置 | 对 CPU FP64 的末状态相对 RMSE |
| --- | ---: |
| 保留内核的全部 BF16 转换 | 5.6316% |
| 只保留 `K̃` 为 FP32 | 3.7260% |
| 只保留 `V_new` 为 FP32 | 5.4635% |
| 只保留 `K̃ᵀ @ V_new` 的结果为 FP32 | 5.6251% |
| 只保留最终写出的状态为 FP32 | 5.6303% |
| 状态递推全 FP32，仍使用 NPU 的 W/U | 3.4114% |
| W/U 和状态递推全 FP32，仍使用 NPU 的逆矩阵 | 2.0083% |

NPU 输入对照保持原样本的 Q、V 和初始状态。仅降低 K 的相关性、增强 gate 衰减或降低 beta，均能使这一组用例通过。K 加少量随机扰动后为 4.6399%，换成独立键后为 0.6681%。只增强衰减后为 1.8210%，只将 beta 降到 0.5 后为 3.7382%。
