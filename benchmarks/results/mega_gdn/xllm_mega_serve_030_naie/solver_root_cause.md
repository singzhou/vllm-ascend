# MegaChunkGdn BF16 三角求逆根因

被测版本为 xLLM `43fc82b8`、910B3、BF16。使用真实服务捕获的 TP2 输入 `debug/nonfinite-71202.pt` 做单算子重放，输入长 2048 token，本地 Q/K 4 个 head，V 12 个 head。Q/K/V、门控、beta 和初始状态均有限。直接使用硬件输出的 BF16 KKT 矩阵，计算同一矩阵的 FP64 三角解作为参考。记录最大绝对误差和求逆残差，本实验没有定义生产精度验收容差。

## 误差起点

首个 128-token 块的 head 4 上，FP64 逆矩阵最大绝对值为 1，NPU 为 593920。CPU 按原 BF16 回写顺序逐元素复现了该矩阵。完整 TP2 输入的 192 个逆矩阵中，CPU 模拟有 173 个与 NPU 逐元素一致，最大误差的量级和 16 个超过校验幅度的矩阵也一致。

在 `InvertSingleTile` 对应的 16×16 对角块里，幂级数用重复平方构造高次项。中间和一度达到约 1072，八次幂项的最大绝对值达到 2080，准确相消后最终逆矩阵的最大绝对值为 1。中间幂和累加值反复回写 BF16。在 16×16 基础块结束时，错误已达到 9.81。污染后的逆矩阵块参与递归拼接，误差继续放大。

| 已完成的块宽度 | 原始 BF16 路径的最大绝对误差 |
| ---: | ---: |
| 16 | 9.81 |
| 32 | 58.25 |
| 64 | 3024 |
| 128 | 593920 |

## 对同一 KKT 矩阵做 CPU 消融

| 变体 | 首块 head 4 最大绝对误差 | 192 个矩阵的最大绝对误差 | 最大绝对值超过 2 的矩阵数 |
| --- | ---: | ---: | ---: |
| 原始 BF16 回写 | 593920 | 2056192 | 16 |
| 只把递归拼接改为 FP32 | 587883 | 2039808 | 16 |
| 只把 16×16 的幂改为 FP32 | 2096 | 2096 | 16 |
| 只把 16×16 的累加改为 FP32 | 224256 | 311296 | 16 |
| 16×16 的幂和累加都为 FP32，完成后转 BF16，拼接保持 BF16 | 0.000922 | 0.00193 | 0 |
| 16×16 改为 FP32 三角前代，完成后转 BF16，拼接保持 BF16 | 0.000800 | 0.00193 | 0 |

修复位置是 16×16 对角求逆的中间数值处理。CPU 消融支持保留基础块中间精度，或用 FP32 前代替代幂级数。两种方式的 Ascend C 实现、完整算子精度和性能仍需上板验证。服务侧的回退保护发生在 Mega 完整执行之后，且使用原输入和旧状态重跑 FLA。

TP0 的抓取样本已包含非有限输入，只把其中有限的 84 个 KKT 块作为辅助记录。根因和改动效果以全部输入有限的 TP2 样本为依据。
